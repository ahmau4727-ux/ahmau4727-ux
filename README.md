## 🔍 What I do

I research how AI systems fail: **prompt injection, system-prompt extraction, and the security boundaries of LLM APIs**.

I found and reported a reproducible system-prompt extraction vulnerability in Google's Gemini API through the official Google VRP — including a full responsible-disclosure report with reproduction methodology, multi-campaign test matrix, and severity analysis.

## 🧪 Research highlights

- **System-prompt extraction on Gemini (gemini-3.5-flash-lite)** — 50% leak rate across two independent campaigns; refusal boundary shown to be probabilistic, not structural
- **Indirect prompt injection chains** — untrusted third-party content overriding model behaviour in routine tasks
- **Full VRP lifecycle** — report → triage → appeal with expanded evidence → final decision → documentation
